# FB/IG funnel · vizuálne overenie

Snímky z automatizovaných testov existujúcej administrácie. **Obsahujú označené testovacie údaje, nie skutočné výsledky predaja alebo reklám.** Do produkčného dashboardu sa ukážkové dáta ani tieto snímky nevkladajú.

Overenie: Chrome a Safari pri šírkach 320–1920 px, súčty zdrojov, filtre a zmena unikátneho režimu, nepriradené nákupy, neúplné a chýbajúce Meta dáta, chyba importu a zachované finančné ukazovatele. Bez vodorovného posunu stránky. Pri 200 % písme sa výsledné finančné karty presunú pod seba; obsah môže prirodzene pokračovať zvislo.
